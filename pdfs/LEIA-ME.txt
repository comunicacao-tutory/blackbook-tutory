Os PDFs desta pasta nao usam nome legivel de proposito.

O nome vem do SHA-256 de sal + numero da parte + palavra-chave.
A URL do PDF nao aparece no codigo-fonte da pagina, e quem nao
ouviu a palavra nao consegue montar o endereco.

Palavras em uso:

  parte 1  Tutoryhub   ->  2192cf06dd78d67ae202.pdf   (20/10)
  parte 2  Tutoryhub2  ->  14640f0f2bc8b98ad0ad.pdf   (21/10)
  parte 3  Tutoryhub3  ->  cb1d3554a6d9355b3484.pdf   (22/10)

Para trocar a palavra de uma noite:

  1. python3 gerar-chave.py "a palavra nova"
  2. renomeie o PDF daquela parte para o nome impresso
  3. ajuste o vercel.json, que define o nome do download
  4. git add . && git commit && git push

A normalizacao ignora maiuscula, acento e espaco: "Tutory Hub 2"
e "tutoryhub2" abrem o mesmo arquivo.

Lembrete: isso esconde o arquivo, nao protege o arquivo. Quem
recebeu a palavra pode repassar o link para qualquer pessoa.
